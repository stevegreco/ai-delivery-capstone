## Oddities

_Written by Steve: at least 3 things in the profile that look surprising, inconsistent or deliberately planted, and why._

1. **Epics and releases don't point anywhere.** `epic_id` (in `requirements` and `user_stories`) and `release` (in several files) are used as references, but there is no epic file and no release file for them to point to.
2. **Everything is in scope.** `release_scope.in_scope` is `YES` on all 135 rows; nothing is out of scope.
3. **Only 5 of the 8 documents are pointed to.** Requirements cite `DOC-01`, `02`, `03`, `05` and `06`. No requirement cites `DOC-04` (checkout UI standards), `DOC-07` (change-request bundle) or `DOC-98` (the archived checkout requirements, v1).
